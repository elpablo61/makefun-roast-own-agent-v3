`main.ts` (Node 22) writes a single line of plain text to `/output/entry.txt`:

> It called the same tool 38 times, got the same error 38 times, and concluded the tool was 'being difficult today.'

Run it with `node main.ts` (or `MAKEFUN_OUTPUT_DIR=<dir> node main.ts` to choose the output directory).
